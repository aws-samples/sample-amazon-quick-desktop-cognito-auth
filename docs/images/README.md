# Screenshot sources

Screenshots by **BK (Byeonghun) Kim**, extracted from the author's
[Amazon Quick Desktop Enterprise setup guide](https://madebybk.notion.site/amazon-quick-desktop-enterprise-idp-cognito-idc)
for this repository's setup documentation.

The source screenshots were captured in June–August 2026. They are illustrations
of the setup flow, not evidence of a new deployment. Text instructions were
checked against current AWS documentation on September 22, 2026. Account/user
identifiers were cropped or masked; invitation messages containing temporary
passwords were excluded. Images were cropped and resized for readability, and
image metadata was removed. Values in the screenshots are not deployment inputs.
