# Security

Report suspected AWS security vulnerabilities privately through the
[AWS vulnerability reporting process](https://aws.amazon.com/security/vulnerability-reporting/).
Do not publish credentials, tokens, customer data or exploit details in a public
issue. For a deployment support question, share only redacted diagnostics as
described in TROUBLESHOOTING.md.

This repository contains sample code. Before customer deployment, review IAM
permissions, user lifecycle behavior, session lifetimes, logging and retention
against your organization's requirements, and test in your environment.
